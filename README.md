## Project Description
The University Academic Records and Registration System (UARRS) is a database project developed using Oracle SQL and PL/SQL. It is designed to manage student information, departments, academic programs, courses, semesters, registrations, and academic results.

## Project Objectives
- Store and manage student academic information.
- Manage courses, programs, and semester registrations.
- Record and update students' grades.
- Calculate students' GPA and display academic transcripts.
- Improve the accuracy and organization of academic records.

## Technologies Used
- Oracle Database
- Oracle SQL
- PL/SQL
- Oracle SQL Developer
- GitHub

## Main Features
The system allows users to register students and courses, manage student status, record grades, calculate GPA, count registered courses, and display student transcripts.

## PL/SQL Concepts
The project applies procedures, functions, records, collections, cursors, bulk operations, and exception handling.

## Conclusion
This project demonstrates how Oracle SQL and PL/SQL can be used to develop a university academic records system that organizes student information, manages course registration, and supports academic performance tracking.
